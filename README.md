A Java Spring Boot movie recommendation app — get personalized suggestions, skip movies you're not into, and refine your picks in real time. Web frontend built with HTML/CSS.

---

## ✨ Features

- 🎥 **Personalized recommendations** — Get movie suggestions based on your preferences
- ⏭ **Skip & refine** — Skip movies you've seen or don't want, get better suggestions
- 📋 **Match history** — Track what you've accepted and rejected
- 🌐 **Web UI** — Clean HTML/CSS frontend served by Spring Boot
- ⚡ **Fast iteration** — Spring Boot hot-reload for quick development

---

| Technology | Purpose |

- **Server-side rendering** with Thymeleaf templates
- **Maven** project structure and dependency management
- Full-stack Java web development without a separate frontend framework

## 🚀 Run Locally

```bash
git clone https://github.com/sonnymay/Movie-Matcher
cd Movie-Matcher
mvn spring-boot:run
```

Then open [http://localhost:8080](http://localhost:8080) in your browser.
